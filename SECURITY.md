# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 0.4.x | Yes |
| Earlier versions | No |

## Reporting a vulnerability

Please report vulnerabilities privately through a [GitHub Security Advisory](https://github.com/howlrs/wp-transfer/security/advisories/new).

Do not open a public issue, include exploit details in a discussion, or publish
credentials, customer inputs, or generated project secrets. Include a concise
impact description, affected version, and reproducible steps using synthetic
data where possible. The maintainers will acknowledge and triage reports
privately.

For operational safeguards and known boundaries, read the [README security
section](README.md#security) and [release limitations](README.md#known-limitations).
